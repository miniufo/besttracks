Contributors
============

`besttracks` is meant to be an open-source package and we welcome feedback and
contributions.

You can `open an issue in the github issues page
<https://github.com/miniufo/besttracks/issues>`__ if you:

- find a bug in the package;
- need some new features;
- want some supports;
- have your own examples.

If you have a cool or new example that can be fit into `besttracks`, please
consider contributing to `Examples
<https://github.com/miniufo/besttracks/tree/master/notebooks>`__ in a form of
Jupyter Notebook.  Generally, the notebook contains:

- an introduction of the best-track dataset;
- a demonstration of parsing and reading the data;
- associated plotting or analysis.

In order to contribute to `besttracks`, please

- fork the repository,
- modify the codes, and
- send a pull request (PR).

We are looking forward to your contributions.
