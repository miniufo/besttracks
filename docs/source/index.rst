Welcome to besttracks's documentation!
======================================

.. image:: https://raw.githubusercontent.com/miniufo/besttracks/master/pics/Global_TC_tracks.png

This is a `Python` package that provides a unified interface to access tropical
cyclone best-track datasets in different formats from several agencies
including JTWC, CMA, JMA, and NHC.

This project is `published on GitHub <https://github.com/miniufo/besttracks>`__
and can be cited using its `Zenodo DOI
<https://doi.org/10.5281/zenodo.5714995>`__.
